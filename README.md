# Слова и Дары — Godbound

Справочник по Словам и Дарам системы Godbound (НРИ). В начале: 71 Слово, 648 Даров. Статическая HTML-страница с поиском и фильтрами по типу/уровню, без сервера и базы данных.

Цель проекта — сделать редактируемый справочник.

## Структура

- `content/words/*.yml` — По одному файлу на Слово, с вложенным списком его Даров. Это редактируемые данные.
- `content/order.yml` — порядок Слов на странице (сперва по типу: рулбук → анафема → дополнение → самописные, внутри группы по алфавиту).
- `images/icons/words/*.webp`, `images/icons/gifts/<слово>/*.webp` — иконки.
- `template.html` — статический каркас страницы (шапка, CSS, JS поиска/фильтров) с тремя плейсхолдерами: `{{TALLY}}`, `{{NAV}}`, `{{WORDS}}`.
- `build.js` — Node-скрипт сборки: подставляет данные из `content/` в `template.html` и пишет `index.html`.
- `index.html` — собранная страница. Генерируется командой сборки, руками не редактируется — правки потеряются при следующей сборке.

## Сборка

```
npm install   # один раз
npm run build # пересобрать index.html из content/ и template.html
```
